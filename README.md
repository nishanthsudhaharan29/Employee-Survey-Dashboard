# Employee Survey Data Analysis Project

## Project Description

This project involves analyzing employee survey data to gain insights into various aspects such as average salary, preferred programming languages, job titles, and overall satisfaction levels. The analysis was conducted using Power BI to create an interactive dashboard that visualizes key metrics and trends within the data.

---

## Project Walkthrough

### 1. Data Collection
- The employee survey data was collected from a survey with 630 respondents, covering various job titles, countries, and programming language preferences.

### 2. Data Cleaning
- The survey data was cleaned to ensure accuracy and consistency. This involved:
  - Handling missing values
  - Correcting data entry errors
  - Standardizing formats for consistency

### 3. Data Analysis
- The cleaned data was analyzed to calculate key metrics such as:
  - **Average Age**: 29.87 years
  - **Average Salaries** across different job titles and countries
  - Job titles included:
    - Data Scientist
    - Data Engineer
    - Data Architect
    - Data Analyst
    - Database Developer
    - And more...

### 4. Dashboard Creation
- An interactive dashboard was created using **Power BI** to visualize the following:
  - **Average salary** per job title
  - **Preferred programming languages** among employees
  - **Average salary by country**, including countries such as:
    - United States
    - Canada
    - United Kingdom
    - India
    - Others
  - **Employee satisfaction** with work-life balance and current salary
  
### 5. Insights and Visualization
- The dashboard provides clear visual insights, such as:
  - The most preferred programming language among employees (**Python**)
  - The job title with the highest average salary
  - Satisfaction levels with work-life balance and salary, which are presented on a scale of 0 to 10:
    - **Work-life balance satisfaction**: 5.86
    - **Salary satisfaction**: 4.27

This project highlights the importance of data cleaning in ensuring accurate analysis and the power of data visualization tools like Power BI in presenting actionable insights from employee survey data.

---

## Key Features of the Dashboard

- **Salary by Job Title**: Visual representation of the average salary for each job title.
- **Programming Language Preferences**: Insights into the most popular programming languages among employees.
- **Country-Based Salary Insights**: A comparison of average salaries across different countries.
- **Satisfaction Analysis**: Visuals of employee satisfaction in terms of work-life balance and salary.

## Tools and Technologies

- **Data Cleaning and Analysis**: Python (Pandas, NumPy)
- **Data Visualization**: Power BI
- **Dataset**: Employee survey data from 630 respondents
